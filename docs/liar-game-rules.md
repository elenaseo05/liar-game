# 라이어 게임 룰 정리 (제시어 기반)

- 작성일: 2026-02-24
- 적용 범위: 한국에서 모임/파티에서 자주 하는 `제시어 기반 라이어 게임` 기준

## 1. 게임 목적

- `시민(일반 플레이어)`은 라이어를 찾아내는 것이 목표입니다.
- `라이어`는 정체를 숨긴 채 대화에 섞여들고, 최종적으로 제시어를 맞히는 것이 목표입니다.

## 2. 인원과 준비물

- 인원: 최소 3명 이상 (권장 4~15명)
- 준비물: 제시어 목록(앱/카드/종이), 라이어를 정할 방법(랜덤), 투표 방법(손들기 등)

## 3. 기본 진행 순서

1. 라운드 시작: 플레이어 중 1명을 라이어로 랜덤 지정합니다.
2. 제시어 확인: 시민만 같은 제시어를 확인하고, 라이어는 제시어를 모릅니다.
3. 힌트 발언: 순서대로 제시어와 관련된 힌트를 한 마디씩 말합니다.
4. 토론: 발언을 바탕으로 누가 라이어인지 토론합니다.
5. 지목/투표: 가장 수상한 사람을 지목합니다.
6. 승패 판정:
   - 지목된 사람이 라이어가 아니면 라이어 승리
   - 지목된 사람이 라이어면, 라이어에게 제시어 추측 기회 1회 부여
   - 라이어가 제시어를 맞히면 라이어 승리
   - 라이어가 제시어를 못 맞히면 시민 승리

## 4. 자주 쓰는 선택 규칙

- 동표 처리: 진행자(또는 이전 라운드 승자)가 최종 결정
- 점수제(옵션):
  - 라이어 미검거: 라이어 2점
  - 라이어 검거 + 제시어 추측 성공: 라이어 1점
  - 라이어 검거 + 제시어 추측 실패: 시민 전원 2점
- 짧은 인원(3인) 보정: 라이어에게 추측 기회를 2회 주는 변형 룰 사용 가능

## 5. 진행 팁

- 힌트는 너무 노골적이면 라이어가 쉽게 맞히고, 너무 모호하면 시민이 의심받기 쉽습니다.
- 한 라운드는 보통 5~10분 내로 끊고, 라이어는 라운드마다 교체하면 좋습니다.
- 제시어 난이도를 인원/친밀도에 맞춰 조정하면 게임 템포가 좋아집니다.

## 6. 제시어 기준 (출처 기반 정리)

- 먼저 결론: `라이어 게임`에는 단일 국제 표준 규칙이 없고, 앱/보드게임 버전에 따라 제시어 운용 방식이 다릅니다.
- 다만 여러 출처에서 겹치는 `공통 기준`은 아래와 같습니다.

### 6-1. 라운드 시작 전 제시어 선정 기준

1. `카테고리(주제)`를 먼저 정하고, 그 안에서 제시어를 뽑는다.
2. 제시어는 라이어를 제외한 플레이어가 공유하고, 라이어는 모르는 상태로 시작한다.
3. 제시어는 매 라운드 랜덤으로 바뀌게 구성하는 것이 일반적이다.

근거
- App Store `LIAR GAME: WHO IS LIAR`: 플레이어/라이어 수 선택 후 카테고리를 고르고 제시어 확인 절차를 명시.
- App Store `광고없는 라이어게임`: 자동 키워드 랜덤 선택, 사용자 카테고리/단어 추가 기능 명시.
- Big Potato `The Chameleon` 공식 설명: 토픽 카드(주제)와 좌표 방식으로 비밀 단어를 결정.

### 6-2. 라운드 중 설명(힌트) 기준

1. 시민 설명은 `같은 제시어를 아는 사람끼리는 공감`되지만 `라이어가 바로 특정하기는 어렵게` 해야 한다.
2. 힌트가 너무 직접적이면 라이어가 제시어를 맞히기 쉬워지고, 너무 모호하면 시민이 의심받는다.
3. 한 사람당 짧고 명료하게 말하는 방식(한 단어/한마디)이 가장 널리 쓰인다.

근거
- 원스토어 `라이어 게임 - 라이어를 찾아라 Free`: “라이어가 알아차리지 못하게 하지만 서로간 공감할 수 있는 내용”으로 설명.
- Big Potato `The Chameleon` 공식 설명: 너무 obvious/cryptic한 힌트의 위험을 명시, 한 단어 단서 진행을 제시.
- App Store `라이어를 찾아라`: 제시어에 대해 “한마디씩” 반복 발언 권장.

### 6-3. 제시어 데이터(단어 풀) 품질 기준

1. `너무 어려운 단어`는 줄이고, 플레이어 다수가 아는 단어 중심으로 구성한다.
2. 카테고리는 인원/모임 성격에 맞춰 확장(장소, 직업, 음식, 브랜드 등)하는 방식이 일반적이다.
3. 필요 시 커스텀 카테고리/단어를 써서 그룹 친화도를 높인다.

근거
- App Store `라이어를 찾아라` 업데이트 노트: 어려운 단어 제거, 카테고리 확장(장소/직업/빵/꽃 등).
- App Store `광고없는 라이어게임`: 사용자 정의 단어/카테고리 기능 명시.

### 6-4. 실전 적용용 체크리스트

- 제시어는 `한 카테고리 안`에서 선정했는가?
- 같은 모임 인원의 `공통 배경지식`으로 이해 가능한가?
- 라이어가 힌트 1~2개만으로 바로 맞힐 정도로 노골적이지 않은가?
- 반대로 너무 마이너해서 시민끼리도 설명이 엇갈리지 않는가?
- 라운드마다 랜덤/교체되어 반복 학습(외워짐) 문제가 줄어드는가?
